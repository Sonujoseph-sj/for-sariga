# For Sariga 💗

A small chat-style love website from Sonu to Sariga. Plain HTML, CSS and JavaScript. No build step.

## What's inside
- Lock screen with a message notification. Tap it to open the chat.
- Sonu "types" each message, like a real chat.
- Yes or no questions. The No button runs away from the mouse and from touch.
- "Why are you blushing?" with an "I'm not blushing" button that also runs away.
- Tricky questions. One answer button changes itself when she tries to tap it.
- A shy envelope that needs 3 taps to open the love letter.
- A final "I love you too" tap with a heart shower.

## Edit the text
Open `script.js`. All messages are in the `story` array. The letter is in the `letter` array below it.

## Test locally
Open `index.html` in a browser. Test on a phone before you send the link.

## Deploy on GitHub Pages
1. Create a public repo, for example `for-sariga`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repo root.
3. Go to Settings > Pages.
4. Source: Deploy from a branch. Branch: `main`, folder `/ (root)`. Save.
5. After a minute, open `https://YOUR-USERNAME.github.io/for-sariga/`.

Note: anyone with the link can open the page. Do not add anything too private.
